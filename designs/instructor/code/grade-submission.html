Part B · Short essay · Subjective
Explain the tradeoffs between encryption-at-rest and tokenization for protecting sensitive cloud data.
20 pts
Learner's answer
Encryption-at-rest protects data using keys managed by the cloud provider or customer, but the data is still fully reversible if the key is compromised. Tokenization replaces sensitive values with non-sensitive tokens, so even if the token store is breached, the original data isn't directly exposed. Encryption is faster for bulk data and simpler to apply broadly, while tokenization is stronger for high-value fields like payment data but requires a separate token vault and adds latency to lookups.
